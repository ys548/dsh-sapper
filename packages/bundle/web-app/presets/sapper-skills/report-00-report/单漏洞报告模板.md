## 复现步骤（含完整数据包，复制即用）

> **⛔ 完整数据包铁律**：每个利用/验证请求的**完整 HTTP 请求 + 完整响应必须逐字内嵌正文**，禁止只写请求行、禁止 `→ 200 {...}` 省略、禁止只指向 evidence 让读者自己翻。evidence 仅作附件备份。

> **⛔ 复制即用三铁律**（数据包给出来就必须能直接粘进 WebFuzzer / curl 发出去）：
> 1. **代码块一律顶格**：` ```http ` 围栏及块内每行**行首零空白**——禁止为列表嵌套缩进（缩进空格会被带进 Yakit/curl → WAF 判畸形请求 400）。宁可断列表渲染，必须顶格。
> 2. **请求与响应用空行分隔**：请求体最后一行之后、`HTTP/1.1 xxx` 状态行之前**必须有一个空行**（GET 无体则请求头空行后再空一行接状态行）。漏空行会把状态行粘进请求体导致后端解析报错。
> 3. **产出后自检（强制）**：逐块检查全部 http 代码块——顶格、请求头与状态行之间必须有空行、结构完整；不过自检不得交付。
