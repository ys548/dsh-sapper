# fofa.py 输出解析(表格格式 + 正则)

> 2026-08-15 客户域名实战(domain 查询 --size 200, 总计 2919 条返回 200 条, 验证通过)

## 输出结构
头部两行:
```
🌐 域名查询: domain="<目标域名>"
📊 总计 2919 条  |  本次返回 200 条
```
`本次返回 N 条` 即 --size 生效的确认行;单次 200 条只是第一页。

表格 8 列(含 `+-+` 分隔线):

| 列 | 语义(实测) |
|----|------------|
| HOST | 完整 URL, 如 `https://ims.<目标域名>:9000` |
| 标题 | 页面标题或状态文本(`404 Not Found` / `503 Service Temporarily Unavailable` / `绿能天赋` / `CCPAAS` / 空) |
| 域名 | 主域 <目标域名> |
| IP | IPv4 |
| 端口 | 数字 |
| 协议 | http / https |
| 指纹 | `nginx/1.30.0`、`Cowboy`、`CCPAAS` 等, 可能为空 |
| URL | 与 HOST 相同 |

## 解析正则(pwsh 起 python 直接用)

```python
import re

    full, re.M)
# 每组 8 字段: url, title, domain, ip, port, proto, server, url2
```

## 解析校验基准(200 条样本量级)
- 去重主机名(从 URL 列提子域): ~198
- 去重 IP: ~32
- 端口分布长尾: 443(72) > 7480(30) > 80(15) > 8080(11) > 9080(10) > 8888(8)
- 若解析结果远低于此量级 → 正则/输出格式可能变了, 先看头部是否报错

## 大目标全量
总条数远大于 200 时(如某客户 2919 条), 一次查询只覆盖第一页。
全量方案: `--all --export`(注意 FOFA 风控间隔 ≥15s, 别 for 循环连查);
或参考 quake skill 的"策略 A 子域名细分 / 策略 C IP 段细分"拼凑思路。
